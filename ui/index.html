🧪 Experiments to Try

  1. Load balancing: Click "Replica Info" 9 times. You should see app-1, app-2, app-3 rotating in the Response Log.
  2. Rate limiting: Set Auto Traffic to 25 req/s, click Start. Watch 429 errors appear (Nginx limit is 20 req/s).
  3. Error detection: Click "Trigger Error" 5 times. Open Grafana → Error Logs panel → see them appear instantly.
  4. Latency spike: Click "Slow Request" 3 times. In Grafana Explore, run: {app="traffic-lab"} | json | duration_ms > 1000
  5. Kill a replica: Run docker compose stop app-3. Watch Grafana's "Active Replicas" drop from 3 to 2. Traffic split changes from 33%/33%/33% to 50%/50%.
  6. Scale up: Duplicate app-3 service as app-4 in docker-compose.yml. Run docker compose up -d app-4. Add server app-4:5000; to nginx.conf, reload Nginx.
